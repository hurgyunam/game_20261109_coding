# 월드

`src/world`의 Phaser 씬이다. 2D 탑뷰로, 화면보다 큰 맵을 카메라가 플레이어를 따라 비춘다. 코어의 상태를 스프라이트로 그리고, 입력을 코어 함수 호출로 바꾼다.

```text
src/world/
  game.ts
  scene.ts
  camera.ts
  input.ts
  assets.ts
```

## 에셋

코어 id마다 이미지 키를 하나 둔다. 파일은 `assets/`에 두고, 임시 그림이어도 이미지 파일로 만들어 키만 바꾸면 교체되게 한다. 코어 상태에는 경로를 넣지 않는다.

## 입력

`input.ts`만 키를 읽는다.

- 방향키는 매 프레임 `move`를 호출한다. 마지막으로 누른 방향키가 캐릭터가 바라보는 방향이고, 시작 시 방향은 아래다
- 숫자키 1–9는 `selectSlot`을 호출한다
- E는 바라보는 방향에 인접한 대상을 고른 뒤 아래로 넘긴다. 누르는 순간 한 번 호출하고, 누르고 있는 동안에는 그 호출을 연타처럼 반복한다. 떼면 반복이 멈춘다

핸드와 대상의 조합은 이렇게 호출한다.

- `stone-axe`와 나무: `chop`
- `stone-axe`와 토끼: `hunt`
- `stone-hammer`와 빈 타일: 좌표를 HUD에 알린다. `place`는 HUD가 호출한다
- `stone-hoe`와 빈 타일: 밭 고스트를 연다. 고스트는 바라본 빈 칸 하나에서 초록색으로 시작하고, 마우스가 움직이면 그 칸을 따른다. 클릭이 시작 칸을 정하고, 다음 클릭이 반대편 꼭짓점을 정한 뒤 `placeField`를 호출한다
- 밭 고스트는 놓을 수 있으면 초록색이다. 한 변이 10칸을 넘거나, 영역 안에 나무, 건물, 토끼를 포함한 야생동물, 상인, 이미 있는 밭이 있으면 빨간색이고 밭은 생기지 않는다
- 액션 키를 누르고 있어도 클릭 없이는 밭 고스트의 다음 단계로 넘어가지 않는다
- 등록된 밭은 연노랑 빗금으로 그린다
- 창고 또는 모닥불: 대상 id를 HUD에 알린다. `transfer`와 `cook`은 HUD가 호출한다

바라보는 방향의 인접 대상이 위 조합에 없으면 상태를 바꾸지 않는다.

## 연출

나무 쓰러짐, 이동, 카메라 추적은 코어 상태가 바뀐 뒤 이 층에서 그린다. 총중량과 속도 계산은 하지 않고, `move`가 돌려준 위치를 따른다.

## 시간 진행

매 프레임 경과 시간으로 `tick`을 호출한다. 이동하지 않아도 같은 속도로 흐른다.
